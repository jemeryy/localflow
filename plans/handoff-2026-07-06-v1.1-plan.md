  instance (launched 09:57 today) records from it, real audio captured since
  10:15, no fallback triggered. Explained to Jeremy that "wedged at OS level"
  means the device opens but delivers 0 frames to every process; replug is
  the only cure and LocalFlow's fallback keeps dictation alive meanwhile.
- Log-measured startup breakdown (grounds M6): launch-to-ready 14-19s total =
  ~5-7s Python+imports, ~3s Whisper GPU compile (warm cache), 5-11s warmup
  pass. Warmup blocking readiness is the fixable part.
- Learning-from-corrections constraint: LocalFlow cannot see edits Jeremy
  makes in the target app after paste, so corrections need their own surface
  (History panel in settings). Dictionary = post-STT deterministic text
  replacement, deliberately NOT hot_words (known live failure 3 Jul).
- Settings window threading decision: one Tk root per process — the settings
  window is a Toplevel on the overlay's existing UI thread, which will exist
  in all visibility modes (window hides, thread stays).
