## Important discoveries and decisions
- **COM crash root cause (crash.log, twice recorded):** in
  `micgain._endpoint_volume`, `device.Activate` returns a comtypes pointer
  owning the SINGLE COM ref; `ctypes.cast` wrapped the same address in a
  second owning wrapper (no AddRef). Two `__del__` Releases, one ref: the
  leftover wrapper Released the freed object during cyclic GC on the Tk
  thread (mid pill-drag `save_config` -> tomlkit alloc -> GC) = access
  violation, process death. Best fit for the 13 Jul crashes too. Fix:
  ownership transfer (memset the intermediate to zero).
- **Pause punctuation:** Whisper punctuates every pause-bounded hypothesis
  like a sentence end. Design iterated live with Jeremy in THIS order: (a)
  hold the mark, case-heuristic (superseded); (b) Jeremy OK'd
  punctuation-only edits: type at once, backspace if wrong (superseded); (c)
  FINAL: boundary rule, all marks `.,!?;:` — the trailing mark of the last
  typed word stays provisional until the next words arrive, then is
  added/replaced/removed to match that word's surface in the newer decode or
  authoritative segment text (norm-guarded against word drift); across a
  Tier 1 cut (no later decode re-hears the boundary) the fallback drops a
  trailing `.!?` before a lowercase continuation. WORDS ARE STILL NEVER
  REVISED.
- **Two injection bugs found via live runs into VS Code/Electron
  (`Chrome_WidgetWin_1`):** (1) class sniff missed Electron's outer window ->
  backspaces went as 0x08 chars Chromium ignores (marks survived, "subscription., not");
  fixed by prefix match ("Chrome_", "Mozilla"). (2) with the key pair
  landing, Chromium paired the key-down with the NEXT char message and ate
  the leading space of the retype ("thoughgo"); fixed by posting the full
  hardware sequence down + char 0x08 + up per backspace. Classic edit
  controls keep the bare 0x08 path. Each dictation now logs
  `live target hwnd=... class=...` for instant diagnosis.
- **Trailing words waiting until release is DESIGN, not a bug** (explained to
  Jeremy, he did not push back): LocalAgreement-2 needs two agreeing decodes;
  the final tail lands ~1s after release. Do not commit on one decode.
